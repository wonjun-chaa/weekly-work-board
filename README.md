# 주간 업무 보드

회사 업무를 주 단위로 관리하는 Windows 데스크톱 앱입니다. 월요일부터 금요일까지 요일별 열에 업무 카드를 배치하고, 기한 없는 일은 장기 업무 열에 따로 보관합니다.

![구성] 월 · 화 · 수 · 목 · 금 ┆ 장기 업무

## 주요 기능

### 카드 관리
- **드래그 앤 드롭** — 카드를 끌어서 요일 간 이동, 같은 열 안에서 순서 변경, 장기 업무 ↔ 요일 이동이 모두 가능합니다.
- **카드 정보** — 제목, 메모, 우선순위(높음·보통·낮음), 태그, 마감기한을 설정할 수 있습니다. 카드를 클릭하면 편집·삭제할 수 있습니다.
- **완료 체크** — 체크하면 취소선 처리되고 완료 시각이 기록됩니다. 열마다 완료율 진행바가 표시됩니다.

### 주간 흐름
- **주차 이동** — 헤더의 ◀ ▶ 버튼으로 지난주·다음주를 오가며 볼 수 있고, "오늘" 버튼으로 이번 주로 돌아옵니다. 오늘 요일 열은 테두리로 강조됩니다.
- **미완료 오늘로 이월** — 지난 요일에 남은 미완료 카드를 버튼 하나로 오늘 열에 모아줍니다.

### 태그와 필터
- 한 번 만든 태그는 카드 편집창에서 클릭으로 재사용할 수 있습니다.
- 태그마다 파스텔 색상 8종 중 하나를 지정할 수 있고, 상단 툴바에서 태그별 필터링이 됩니다.
- 사용 중인 카드가 없는 태그는 편집창에서 ×로 삭제할 수 있습니다. (사용 중이면 개수와 함께 삭제 불가 안내)

### 마감기한 알림
- 마감 **하루 전부터** 카드가 빨간 테두리와 "내일 마감 / 오늘 마감" 표시로 강조됩니다. 기한을 넘기면 "N일 지남"으로 표시됩니다.

### 기타
- 라이트/다크 테마 — 헤더의 ☀/☾ 슬라이드 스위치로 전환, 선택이 저장됩니다.
- 완료 숨기기 토글, 주간 전체 진행률 표시.

## 트레이 상주와 자동 시작

- 창을 **X로 닫아도 앱은 종료되지 않고** 작업 표시줄 트레이에 남습니다. 트레이 아이콘을 더블클릭하면 다시 열립니다.
- **Windows 로그인 시 자동으로 시작**됩니다(창 없이 트레이로 조용히 시작). 트레이 아이콘 우클릭 → "Windows 시작 시 자동 실행"에서 켜고 끌 수 있습니다.
- 완전히 종료하려면 트레이 우클릭 → "종료"를 누르세요.

## 월별 CSV 기록

업무를 추가·수정·완료할 때마다 CSV 파일이 자동으로 갱신됩니다.

- 저장 위치: `문서\주간업무보드\`
  - `업무기록-2026-07.csv` 처럼 **월별 파일**로 저장됩니다.
  - 장기 업무는 `장기업무.csv`에 따로 저장됩니다.
- 열 구성: 날짜, 요일, 제목, 우선순위, 태그, 마감기한, 완료 여부, 완료일, 메모, 등록일
- 엑셀에서 바로 열어도 한글이 깨지지 않습니다. 앱 툴바의 **"CSV 폴더 열기"** 버튼 또는 트레이 메뉴로 폴더를 바로 열 수 있습니다.

## 실행 방법

- 바탕화면의 **"주간 업무 보드"** 바로가기를 더블클릭하거나,
- 이 폴더에서 터미널로:

```
npm install   # 최초 1회
npm start
```

> 참고: 이 PC 환경에서 electron 설치 시 압축 해제가 실패하는 경우가 있습니다. 그 경우 `node_modules\electron\dist`에 Electron zip을 수동으로 풀고 `path.txt` 파일(내용: `electron.exe`)을 만들어 주면 됩니다. 자세한 내용은 `CLAUDE.md` 참고.

## 데이터 위치

| 항목 | 경로 |
|---|---|
| 업무 데이터 | `%APPDATA%\weekly-work-board\board-state.json` |
| CSV 기록 | `문서\주간업무보드\` |

앱을 삭제해도 위 데이터는 남습니다. 백업하려면 두 위치를 복사하면 됩니다.

## 기술 구성

- **Electron** 단일 창 앱 — `main.js`(창·트레이·자동 시작·CSV), `preload.js`(IPC 브리지), `renderer/index.html`(UI 전체)
- 외부 라이브러리 없이 순수 HTML/CSS/JS로 작성된 UI
- 디자인: 그린그레이 중성색 + 틸 액센트의 "유칼립투스 어스톤" 팔레트, 태그용 뮤트 파스텔 8색
